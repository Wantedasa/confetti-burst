# Confetti Burst 🎉

Canvas confetti on click — no libraries, one small script.

## What it is
A canvas-based confetti burst. Click anywhere to fire a shower of colored particles that fall and fade. Self-contained, no libraries — just a <canvas> and a small physics loop.

## Usage
```js
confetti(x, y)
```
